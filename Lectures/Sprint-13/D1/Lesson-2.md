# Authentication and Authorization

---

## JSON Web Tokens (JWT)

JWT is a compact, URL-safe means of representing claims to be transferred between two parties.
<!-- element class="fragment" -->

- A JWT is a string that consists of three parts, separated by dots (`.`):
  - **Header**: Contains the token type and the signing algorithm.
  - **Payload**: Contains the claims (e.g., user ID, roles).
  - **Signature**: Used to verify that the sender of the JWT is who it says it is and to ensure that the message wasn't changed along the way.

---

## Creating a Token for a User on Login

After a user logs in, we can create a JWT to send back to them.

```javascript
const jwt = require('jsonwebtoken');

// ...

const token = jwt.sign({ _id: user._id }, 'your-secret-key', { expiresIn: '7d' });

res.send({ token });
```
<!-- element class="fragment" -->

- `jwt.sign()` takes a payload, a secret key, and an options object.
- The payload contains the data we want to store in the token.
- The secret key is used to sign the token.
- `expiresIn` sets an expiration date for the token.

---

## Authorization Middleware

We can create a middleware function to protect routes that require authentication.

```javascript
const jwt = require('jsonwebtoken');

const auth = (req, res, next) => {
  const { authorization } = req.headers;

  if (!authorization || !authorization.startsWith('Bearer ')) {
    return res.status(401).send({ message: 'Authorization required' });
  }

  const token = authorization.replace('Bearer ', '');
  let payload;

  try {
    payload = jwt.verify(token, 'your-secret-key');
  } catch (err) {
    return res.status(401).send({ message: 'Authorization required' });
  }

  req.user = payload;
  next();
};

module.exports = auth;
```
<!-- element class="fragment" -->

This middleware checks for a valid token in the `Authorization` header.
<!-- element class="fragment" -->

---

## Creating an Item for a User

Now we can use our `auth` middleware to protect a route for creating an item.

```javascript
const express = require('express');
const router = express.Router();
const auth = require('../middleware/auth');
const Item = require('../models/item');

// ...

router.post('/items', auth, async (req, res) => {
  const { name, description } = req.body;
  const owner = req.user._id;

  const item = await Item.create({ name, description, owner });

  res.send(item);
});
```
<!-- element class="fragment" -->

- The `auth` middleware is passed before the route handler.
- If the token is valid, `req.user` will contain the user's ID, which we can use to associate the item with the user.

---

## Updating an Item and Authorizing

When updating an item, we need to ensure that the user making the request is the owner of the item.

```javascript
router.patch('/items/:itemId', auth, async (req, res) => {
  const { itemId } = req.params;
  const { name } = req.body;
  const userId = req.user._id;

  const item = await Item.findById(itemId);

  if (!item) {
    // Handle item not found
  }

  if (String(item.owner) !== userId) {
    return res.status(403).send({ message: 'Forbidden' });
  }

  const updatedItem = await Item.findByIdAndUpdate(itemId, { name }, { new: true });

  res.send(updatedItem);
});
```
<!-- element class="fragment" -->

- We check if the `owner` of the item matches the ID of the user making the request.
