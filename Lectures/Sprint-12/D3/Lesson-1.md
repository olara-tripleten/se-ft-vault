# Error Handling

---

## Why error handling?

Proper error handling is crucial for building robust and reliable applications. It helps you to identify and fix issues, and it provides a better user experience by preventing the application from crashing.

<!-- element class="fragment" -->

---

## Using Postman to Test

Postman can be used to test for errors by sending invalid requests to your API.

<!-- element class="fragment" -->

- Send a request with a missing required field.
- Send a request with an invalid data type.
- Send a request for a resource that does not exist.

<!-- element class="fragment" -->

---

## Running a suite of tests on postman

Postman allows you to create collections of requests, which can be run as a suite of tests. This is useful for automating your testing process.

<!-- element class="fragment" -->

---

## Types of Postman Tests

Postman allows you to write tests in JavaScript. You can test for:

<!-- element class="fragment" -->

- Status code
- Response headers
- Response body

<!-- element class="fragment" -->

```javascript
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

pm.test("Body matches string", function () {
    pm.expect(pm.response.text()).to.include("string_you_want_to_search");
});
```

## Proper error handling

In Express, you can create a centralized error handling middleware.

<!-- element class="fragment" -->

```javascript
app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send('Something broke!');
});
```

<!-- element class="fragment" -->

You can also create custom error classes to handle specific types of errors.

<!-- element class="fragment" -->

```javascript
class NotFoundError extends Error {
  constructor(message) {
    super(message);
    this.statusCode = 404;
  }
}
```
