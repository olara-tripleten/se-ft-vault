## Getting started

Clone the github repository that is on your `Github account`, you can search it as `se_project_spots`

- It will appear on your github account as soon as you reach the project lecture <!-- element class="fragment" -->
- If it doesn't appear on your profile **after reaching the Spots stage 1**, you can go to our public template and create a new repository from it https://github.com/tripleten-com/se_project_spots <!-- element class="fragment" -->

---

## Cloning the project

On github.com:

- Navigate to your repositories
- Search the repository by `se_project_spots` and click on it
- Click the green `Code` button and then select the `SSH` key
- Run the command `git clone SSH-URL`
  note:

## Creating the folder structure

---

What you start with:

```
├── .gitignore
└── README.md
```

---

By the end of this stage your projects folder should look like this:

```
├── blocks
│   └── page.css
├── images
│   ├── ...
│   ├── ... image files
|   └── ...
├── pages
│   └── index.css
└── vendor
    ├── fonts
    │   ├── (empty for now)
    ├── fonts.css
    └── normalize.css
├── .gitignore
├── .prettierignore
├── favicon.ico
├── index.html
└── README.md
```
