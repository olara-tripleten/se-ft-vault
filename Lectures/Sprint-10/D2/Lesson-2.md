# Async React

---

## Fetch API Refresher

The Fetch API is a modern interface for fetching resources (e.g., across the network). It is a promise-based API that makes it easy to make asynchronous requests.

```javascript
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
```

---

## Using fetch with React

You can use the Fetch API in your React components to fetch data from an API and display it in your application. The best place to make API calls in a React component is in the `useEffect` hook.

---

## Effects

The `useEffect` hook is used to perform side effects in your components. Fetching data is a side effect, so it should be done in the `useEffect` hook. This ensures that the data is fetched after the component has rendered.

---

## Getting data from an API using Effects/State/Fetch

Here is an example of how to fetch data from an API and display it in a React component:

```jsx
import React, { useState, useEffect } from 'react';

function MyComponent() {
  const [data, setData] = useState(null);

  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(response => response.json())
      .then(data => setData(data));
  }, []); // The empty array ensures that the effect only runs once

  if (!data) {
    return <p>Loading...</p>;
  }

  return <p>Data: {data.name}</p>;
}
```

---

## Optional Chaining

Optional chaining (`?.`) is a JavaScript feature that allows you to safely access nested properties of an object without having to check if each property exists. This is particularly useful when working with data from an API, as the data may not always have the expected structure.

```javascript
const user = {
  name: 'John Doe',
  address: {
    street: '123 Main St'
  }
};

const street = user.address?.street; // '123 Main St'
const zip = user.address?.zip; // undefined
```
