## Context Recap

The React Context API is a way to manage global state in a React application. It allows you to share data between components without having to pass props down through the component tree.

To use the Context API, you first create a context object using `React.createContext`. Then, you use a `Provider` component to make the context value available to all components in the tree. Finally, you use the `useContext` hook to subscribe to the context and get the current context value.

---

## Practical Usage

The Context API is useful for sharing data that can be considered "global" for a tree of React components, such as the current authenticated user, theme, or preferred language.

When a component needs to access the global state, it can subscribe to the context and get the data it needs, without having to receive it as props from its parent component.

---

## Example: Theme Switcher

Let's consider an application that has a theme switcher that allows the user to switch between a light and a dark theme. The current theme is a piece of global state that needs to be accessed by many components in the application.

Instead of passing the current theme as a prop to every component, we can use the Context API to make the theme available to all components that need it.

```jsx
// Create a context for the theme
const ThemeContext = React.createContext('light');

// Create a component that provides the theme
function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(theme === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

// Use the theme in a component
function MyComponent() {
  const { theme, toggleTheme } = useContext(ThemeContext);

  return (
    <div className={`my-component ${theme}`}>
      <p>The current theme is {theme}</p>
      <button onClick={toggleTheme}>Toggle Theme</button>
    </div>
  );
}
```
