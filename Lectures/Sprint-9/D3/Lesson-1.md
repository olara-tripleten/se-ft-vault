# React State and Rendering

---

## Recap: What is State?

In React, "state" refers to a JavaScript object that stores a component's data. This data can change over time, and when it does, the component re-renders to reflect the new state. State is private and fully controlled by the component.

---

## Introducing the `useState` hook

The `useState` hook is a function that allows you to add state to your functional components. It takes an initial state as an argument and returns an array containing the current state and a function to update it.

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  // ...
}
```

---

## Managing State in a Component

To manage state in a component, you call the state update function (e.g., `setCount`) with the new state value. When you call this function, React will re-render the component and its children.

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
```

---

## The `.map()` method

The `.map()` method is a standard JavaScript array method that is commonly used in React to render lists of data. It creates a new array by calling a provided function on every element in the calling array.

```javascript
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(number => number * 2);
// doubled is [2, 4, 6, 8, 10]
```

---

## Rendering Lists of Data with `.map()`

You can use the `.map()` method to iterate over an array of data and return a new array of JSX elements. This is a common pattern for rendering lists in React.

```jsx
const products = [
  { title: 'Cabbage', id: 1 },
  { title: 'Garlic', id: 2 },
  { title: 'Apple', id: 3 },
];

const listItems = products.map(product =>
  <li key={product.id}>
    {product.title}
  </li>
);

// In your component
<ul>{listItems}</ul>
```

---

## Key Prop in Lists

When you render a list of elements using `.map()`, you need to provide a unique `key` prop for each element. The `key` helps React identify which items have changed, are added, or are removed. This allows React to efficiently update the UI.

Keys should be stable, predictable, and unique. It's best to use a unique ID from your data as the key.

---

## Conditional Rendering

Conditional rendering in React allows you to render different UI elements based on certain conditions. You can use standard JavaScript constructs like `if` statements, `&&` operator, or the conditional (ternary) operator to achieve this.

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h1>Welcome back!</h1>;
  }
  return <h1>Please sign up.</h1>;
}
```
