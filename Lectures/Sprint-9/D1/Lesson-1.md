# Introduction to React I

---

## What is React?

React is a popular JavaScript library for building user interfaces (UIs). It was developed by Facebook and is now maintained by a community of developers.

Key features of React include:

- **Component-Based:** React allows you to break down your UI into reusable components, making your code more modular and easier to manage.
- **Declarative:** You describe what your UI should look like, and React takes care of updating the DOM to match that description. This makes your code more predictable and easier to debug.
- **Learn Once, Write Anywhere:** React can be used to build web, mobile, and desktop applications.

---

## Introduction to Web Applications and Frameworks

Web applications are dynamic websites that allow users to interact with the content. Unlike static websites, which only display information, web applications can respond to user input, process data, and perform a wide range of tasks.

Frameworks like React provide a structured way to build web applications. They offer pre-written code and tools that handle common development tasks, allowing you to focus on building the unique features of your application.

---

## Component-Based Development

Component-based development is a software engineering approach that involves building UIs from a set of reusable components. Each component is a self-contained piece of the UI that has its own logic and appearance.

This approach has several benefits:

- **Reusability:** Components can be reused throughout your application, saving you time and effort.
- **Modularity:** Components are independent of each other, making your code easier to understand, maintain, and test.
- **Scalability:** As your application grows, you can easily add new features by creating new components.

---

## The Declarative Approach

React uses a declarative approach to building UIs. This means that you describe the desired state of your UI, and React takes care of updating the DOM to match that state.

For example, instead of writing code that manually manipulates the DOM to show or hide a loading spinner, you can simply declare that the loading spinner should be visible when the `isLoading` state is true.

This approach makes your code more readable, predictable, and easier to reason about.

---

## What is JSX?

JSX (JavaScript XML) is a syntax extension for JavaScript that allows you to write HTML-like code in your JavaScript files. It is not required to use React, but it is a popular and recommended way to build UIs with React.

Here is an example of JSX:

```jsx
const element = <h1>Hello, world!</h1>;
```

JSX code is transpiled into regular JavaScript code before it is executed in the browser.

---

## React Component Structure

A React component is a JavaScript function or class that returns a React element. Here is an example of a simple functional component:

```jsx
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
```

This component takes a `props` object as an argument and returns a heading element that displays a welcome message.
